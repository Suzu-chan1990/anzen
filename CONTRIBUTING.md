# Contributing to Anzen

Contributions are welcome.

## How to contribute
1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Submit a pull request

## Guidelines
- Follow WordPress coding standards where practical
- Write all code comments in English
- Keep the token format unchanged: existing links must keep working
- `serve.php` must stay independent of WordPress (no WordPress boot)
- Avoid unnecessary dependencies
- Write clear commit messages

## Reporting issues
Please include:
- Anzen version
- WordPress version
- PHP version
- Web server (nginx, Apache, LiteSpeed …) and delivery method (`nginx` or `php`)
- Steps to reproduce

Never post your `config.php` or your `ANZEN_KEY`.
